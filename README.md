# Organizador Automático de Arquivos

Script em Python que organiza uma pasta bagunçada, movendo cada arquivo
para uma subpasta de acordo com seu tipo (Imagens, Documentos, Videos, etc.).

## Como usar

1. Tenha o Python 3 instalado;
2. Execute o terminal:
   python organizador.py
3. Digite o caminho da pasta que deseja organizar.

## Para testar com segurança

python criar_teste.py
python organizador.py
(Digite: pasta_teste)

## Tecnologias

- Python 3;
- pathlib e shutil (bibliotecas padrão)

## Personalização

Para adicionar novos tipos de arquivos, edite o dicionário CATEGORIAS
no início do arquivo organizador.py.
